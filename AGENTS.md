# ClaimTrace foundation

This repository alone is authorized for ClaimTrace application work. Hackathon HQ remains private and separate. Use Python/FastAPI, React/Vite, pytest and a shared JSON Schema. No model inference, cloud writes, deployment, public publication, teammate invitations or credentials in Git. Remote writes require authorization for the exact repository/action. Never copy private HQ records or configuration here.

Director owns integration, Git, task record and shared interfaces. Backend engineer owns backend/ and shared/. Frontend engineer owns frontend/. Research owns only its assigned evidence staging path. QA independently inspects and tests; ask Director before editing another owner's paths. No shared branch switching or staging by subagents.

Every source needs primary URL, publication date, reporting period and document locator. Enforce as-of filtering. Mock fixtures, deterministic calculations and reference conformance are not live sponsor/model integration. Default runtime must never issue inference. Zetaris cloud writes require a separate concrete human approval. Runtime credentials stay server-side; private external config may be referenced locally, never copied here.

Team roles are unassigned. Keep the application small, preserve reusable company/period inputs, and record actual commands, results, limitations and remaining work in work/foundation.md.
